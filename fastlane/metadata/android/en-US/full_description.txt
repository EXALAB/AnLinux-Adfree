<p><b>Note:</b> This app works WITHOUT ROOT, but requires the Termux app.</p><p>This application will allow you to run Linux on Android, by using Termux and PRoot technology, you can run a lots of popular Linux Distributions, such as Ubuntu, Debian, Kali, Parrot Security OS, Fedora, CentOS Stream, Alpine and much more!</p><p>By installing a Linux Distribution using this app, you can run various classic Linux desktop applications such as Emacs, mpv player, Python 3, and lots more for you to discover!</p><p>Various Desktop Environments and Window Managers are also supported, such as KDE, Xfce4, LXDM, Mate, LXQT, Awesome Window Manager, IceWM, and more might be added in the future.</p><p><br><b>Features:</b></p><ul><li>NO ROOT ACCESS REQUIRED!!!</li><li>Lots of Linux distributions are
